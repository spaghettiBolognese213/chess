Hello! This is my implementation of the game chess. It currently is still a work in progress, however you can still download it to try it out. In [Roadmap](#roadmap) the current and upcoming features are shown.

## Requirements
- Java 21
- A graphical environment

## Running Download
- Go to releases and download the `.jar` file in the assets of the latest release.
- Run `java -jar chess-v0.1.0-SNAPSHOT-all.jar`
